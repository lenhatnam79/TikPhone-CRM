# Bắt đầu với Affiliate Desk

1. Giải nén gói phù hợp: **Mac Apple Silicon** hoặc **Windows x64**.
2. Mở `Affiliate Desk.app` trên Mac hoặc `Affiliate Desk.exe` trên Windows. Giữ nguyên các file trong gói Windows.
3. Chờ màn hình workspace. Lần đầu, mã thiết lập đã được điền sẵn trên bản desktop local; nhập tên, email và mật khẩu từ 12 ký tự để tạo tài khoản quản trị.
4. Thêm nhãn hàng, sản phẩm và cơ hội hợp tác. Bản nháp mẫu sử dụng được ngay.
5. Cắm Android, bật USB debugging, chấp nhận quyền trên điện thoại. Vào **Thiết bị Android → Mở điều khiển**, rồi mở TikTok Shop trên màn hình điện thoại.

**Dùng cho đội ngũ:** mặc định mỗi máy có workspace riêng. Cần cấu hình cùng một server CRM để các thành viên chia sẻ dữ liệu. Hướng dẫn nằm trong [README](../README.md), phần “CRM dùng chung cho đội ngũ”.

**AI:** bật khi backend có API key và model phù hợp. Khi chưa cấu hình, app vẫn cung cấp mẫu tin và lưu bản nháp.

Bản phát triển chưa ký phát hành. Bản Mac đã chạy kiểm thử; bản Windows chưa được chạy trên máy Windows. Kết nối TikTok cần thử với điện thoại thật. Toàn bộ trạng thái kiểm thử được ghi trong [TEST-REPORT.md](TEST-REPORT.md).
